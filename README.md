### AI Collaboration

I used chatgpt to ask why i was having a spacing that was looking unexpected, then i understood that browsers apply default margins to elements like <p>, <h1>, and <h2>. When spacing looks unexpected. So, i added margin: 0; to the container i was working with, and that solved it.
